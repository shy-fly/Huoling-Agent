# 安全与隐私

交付采用文件清单打包；排除 .env、.env 备份、数据库、日志、缓存、个人凭据、依赖目录和 .git。
.env.example 只保留空凭据字段，默认不启用外部模型。PDF 是用户此次明确授权纳入的本地演示文献。
包内每个文件经当前本机凭据精确匹配和常见密钥格式检查；记录只包含通过/失败和文件数量，不记录秘密值。
图片全部为本轮应用界面，不显示配置凭据。原始 PDF 的文本与元数据另做相同扫描。

曾暴露的 DeepSeek 密钥与管理员 Token 仍应由账户所有者轮换。
从包里去除密钥不能撤销已泄露凭据；本轮没有操作用户账户或代替轮换。
桌面项目无 .git，无法检查历史提交。未执行远程上传、公开发布或历史重写。

管理员凭据为空时管理接口关闭。PDF 路径仍受集合、文件名和目录边界校验。
问答转比较会核对分块 ID、来源文件、集合和页码；失效或伪造的引用返回 409。
向量检索按当前论文范围过滤；切换数据库后用内容指纹核对并重建索引。
回答引用编号越界时只允许一次依据原证据修复，失败不返回成功模型结果。
joblib 索引只允许从可信本地语料构建，不导入来历不明的缓存。

启用外部模型会发送当前问题及检索片段。本轮验收只向 api.deepseek.com 发送用户已授权材料。
论文公开再分发、全学科科学有效性与生产部署安全均未由本轮验收证明。
