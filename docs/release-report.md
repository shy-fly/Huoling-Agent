## 改动与修复

前端新增结构化 QA 比较上下文和当前/历史问答入口，比较页自动提交并允许切回全库。
后端新增 ID 校验服务；未知或失效证据返回 409，空证据返回 422。
修复论文范围被向量缓存忽略和文献库切换后索引失配。
补充中英术语、命名论文定位、方法正文同页补全及模型引用编号校验。
截图复查发现自动表格行列的小数点错序。复用同一单元读词函数，
修复 3.36、293.29、426.14 与 ± 的保留，新增真实论文回归；旧媒体缓存随版本更新。
首页按本地演示授权恢复论文图表样张。表格行列仍明确标注自动提取、需要对照原图。
沿用前轮导入失败保护、初始化脚本与版本约束；未改变字体、字距或阅读布局。

## 剩余风险

- P0（公开上线前）：已暴露凭据仍须由账户持有人轮换；本包不含这些凭据。
- P1：论文的本地演示授权不等于公开再分发授权；源码开源许可尚未由作者指定。
- P1：同步比较计算的后台取消不完整；长请求或上游繁忙时仍可能超时。
- P1：通用变量耦合、开放域实验提取和模型细节仍有边界，不承诺所有问题都正确。
- P2：字体解析可选依赖警告、模块体积与遗留领域规则仍可后续收敛；Tesseract 分支未执行。

没有 Git 元数据，无法审计历史提交。未推送、公开上传或操作用户账户。
源码修改保存在独立交付目录；桌面原项目未被覆盖。最终包的完整性与密钥扫描结果见外部 release-manifest.json。
