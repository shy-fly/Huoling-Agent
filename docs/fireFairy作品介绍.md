# fireFairy · 火灵

科研人员需要在多篇论文之间核对研究对象、实验条件、结论及其适用范围。
fireFairy 将检索、比较、反证、覆盖分析和实验草案组织在同一个阅读工作台。

系统围绕可追溯的论文和证据 ID 运作。比较保留单位和终点。
反证区分支持与条件性结果，空白雷达统计当前范围的论文与实验记录。
设计模块通过确定性代码生成组合，标记用户输入和待确认条件。
多模态模块定位图表，图谱保存有证据的关系，审计区分未报告与未实施，
演化分析核验出版年份并保留不可比关系。

界面采用暖纸纹理、天蓝色和正文阅读布局，支持从结论回到原文页。
作品重点在于缩短证据核对路径，显式保留数据缺失和科学判断边界。

现阶段局限包括有限知识库、受限的实验提取、同步任务取消不完整、
开放域模型细节需要审阅。问答到比较的自动证据传递和六题真实模型验收已补齐。
